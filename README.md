🎨 SyncBoard – Real-Time Collaborative Whiteboard

🚀 Think Together. Draw Together. Create Together.

SyncBoard is a real-time collaborative whiteboard application that allows multiple users to work together on a shared digital canvas.

Users can draw, sketch, share ideas, and collaborate with others in real time through an interactive online whiteboard.

One Board. Multiple Users. Unlimited Ideas!

---

✨ Key Features

- 🎨 Interactive Whiteboard – Draw and sketch on a digital canvas.
- ⚡ Real-Time Collaboration – Collaborate with multiple users simultaneously.
- 🖱️ Live Cursor Tracking – See other users' cursor movements.
- 🔄 Real-Time Synchronization – Keep canvas changes synchronized.
- 👥 Multi-User Support – Work together on a shared board.
- 💾 Local Data Persistence – Store board data locally using IndexedDB.
- 🌐 WebSocket Communication – Enable real-time communication.
- 📱 Responsive Interface – Simple and user-friendly design.

🧠 How It Works

SyncBoard uses collaborative technologies to synchronize data between multiple users.

1. Users open a shared whiteboard.
2. Drawing actions are captured on the canvas.
3. Yjs manages shared collaborative data.
4. WebSocket communication transfers updates between connected users.
5. Other users receive synchronized updates in real time.
